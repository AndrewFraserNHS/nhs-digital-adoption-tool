Design Notes for the Adoption Engine 

The pattern is intentionally identical to the Vision component: 

{ 

"Component" -> "Outcome" -> "Action" 

} 

Each action contains: 

{ 

"fromStatus": "", 

"toStatus": "", 

"lens": "", 

"category": "", 

"outcomeIds": [] 

} 

This allows the engine to: 

filter actions by maturity transition 

filter by lens 

filter by category 

generate outcome-based recommendations 

calculate outcome coverage 

support future AI-generated recommendations using consistent metadata
